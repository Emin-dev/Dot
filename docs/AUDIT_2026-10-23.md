faster more secure more capable and use mostly apple native solutions only."

existing promises. Class C: needs an owner decision, asked one at a time from
[QUESTIONS_FOR_EMIN.md](QUESTIONS_FOR_EMIN.md). Numbers marked "est." are reasoned, not measured.

## Speed and battery

| # | Class | Finding | Fix | Gain |
| --- | --- | --- | --- | --- |
| N1 | A | The retired Python Kokoro runtime (torch, spaCy, numpy; 872 MB, 29k files) still ships though `dot-voice` never starts it | Drop `Voice/python` from the payload, regenerate the manifest | DMG est. 793 to 550 MB; launch hashing -54% bytes |
| P1/N2 | B (C for a receipt cache) | Every launch re-hashes 22.4 GB of models one file at a time at utility priority | Hash files in parallel at user-initiated priority, 8 MB reads | est. 25 s to 6 s per launch |
| P2 | B | The character renders at 24 to 30 fps forever, even hidden or on battery saver | 10 fps idle; stop when hidden, low power or screen off | largest idle GPU cost |
| P3 | A | The 1 s screen-watch tick calls the window list and Accessibility; no AX timeout anywhere (a hung app can freeze Dot 6 s) | Title-only video check, 0.25 s AX timeout, cached checks | removes the freeze class |
| P4/N8 | A | Mute, volume and audio ducking use AppleScript on the main thread, three copies | CoreAudio, one copy | no 20 to 300 ms stalls |
| P5 | A/B | Six memory queries run one after another, and the front page is read on every turn | `async let`; read the page only when asked | est. 50 ms to 1.5 s per turn |
| P6 | B | The minute-level time sits at the top of the system prompt, so the prompt prefix changes every minute | Move it to the end of the last message | prefill per turn |
| P7 | B | A full 27B call extracts key points after every 20 s lull, even from one question | Need at least 3 user turns; skip on battery | fewer background calls |
| P8 | B | Five capture pipelines and three OCR passes run while idle | One shared frame cache | est. 3 to 5x fewer captures |
| P9, P10 | A | App Nap off for the whole run; a global mouse monitor for scribbles; timers without tolerance | Scope the activity; monitor only while Ctrl-Option is held | est. 14 to 3 wakeups/s |
| P11 | A | Log masking compiles 28 regexes per line | Precompiled rules | 1 to 3 ms per line |
| P12 | B | Logs upload as a new commit every minute | Immutable segments, every 10 min | /20 commits |
| P13 | A | The document watcher reads and hashes on the main thread, and the agent writes its brief into the watched folder (a rescan loop) | Background task; skip unchanged files; write the brief elsewhere | no hitches |
| P15 | B | Each approval loads the 2.5 GB Gemma from scratch | Memoize a verdict for 60 s | est. 1 to 4 s on retries |
| P16/N4/N16 | A | No release profile for the Rust binaries; Kokoro without Apple Accelerate; unused tokio and reqwest features | `lto`, `strip`, `accelerate` (benchmark first) | est. 1.5 to 3x synthesis |
| N6, N11 | A | DNS through `dscacheutil` and Spotlight through `mdfind` subprocesses | `getaddrinfo`, `NSMetadataQuery` | one process less per call |
| P14, P19 | A | 200 ms status polling at load; 10 ms polling sleeps in the research transport; history file rewritten 5 times per turn | Backoff, dispatch sources, cached records | small |
